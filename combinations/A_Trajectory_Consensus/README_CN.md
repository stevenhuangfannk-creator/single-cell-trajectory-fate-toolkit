# A：Monocle3 + Slingshot + scTour——结构与状态连续性

**状态：DESIGN_NOT_RUN / RUN_OK=NOT_TESTED / FIGURE_OK=NOT_TESTED。** 本轮未运行组合，也未使用真实PI数据。

## 1. 为什么组合？

Monocle3提供分区主图，Slingshot提供群级骨架和细胞曲线，scTour提供模型学习的动态排序。它们对同一状态连续性作不同假设，可以揭示参数依赖和结构分歧。

## 2. 比单方法多解决什么？

从“能画出一条线”推进到“哪些分支、连接和顺序较稳健”。一致性只提高对模型稳健性的认识，不产生谱系追踪证据。PAGA是第一轮保留的后续拓扑补充，不是本模块首轮必需项。

## 3. 需要什么输入？

冻结同一成纤维谱系的细胞ID、原始计数及各方法规定的表达尺度、供者/样本/批次、已确认标签和展示坐标。各方法保留各自拟合空间；根的独立依据单独登记。scTour先引用旧结果及PARTIAL问题，旧路径不可访问时先解决可访问性，不重训替代。

## 4. 按照什么顺序运行？

先分别通过三个单方法小例；再冻结真实应用输入（本轮不执行）。依次保存Monocle3分区/图/可达性、Slingshot谱系/曲线/权重、scTour时间及诊断。先匹配拓扑和终端，再在对应谱系内按可信方向比较排序；最后做根、拟合维数和供者敏感性。

## 5. 哪些量可以比较？

可比较同一细胞的谱系内秩、末端注释组成、拓扑是否断连、分支对应与缺失。不能平均三种拟时序，不能比较不同分支的原始距离大小，也不能强制把学习潜空间替换成统一二维UMAP。

## 6. 怎样判断一致？

预登记同细胞/同谱系/同方向后使用Spearman秩相关，报告n、NA规则和分支对应表。供者层面重复这些描述；相关高但分支不同仍需报告。没有通用相关系数阈值代表生物学正确，不为通过阈值调根。

## 7. 冲突怎样解释？

检查根和方向先验、群分辨率、维数、邻域、缺少中间细胞、供者/批次主导及scTour旧问题。共享输入本身会带来相似性。STOP于方向无依据、谱系混杂或断连；PIVOT为无方向状态结构，保留全部不一致结果。

## 8. 最终论文图件与边界

原生结构图、统一展示坐标三方法并列、分支对应表、谱系内秩散点、NA/可达性图及供者敏感性图。文字可写“表达状态结构在所测设定下相容”，不能写“证明State 1转化成6再到7”。
