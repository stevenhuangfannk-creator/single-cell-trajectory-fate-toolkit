# C：CytoTRACE2 + scTour——预测潜能与拟时序对照

**状态：DESIGN_NOT_RUN / RUN_OK=NOT_TESTED / FIGURE_OK=NOT_TESTED。** 本轮未运行组合，也未使用真实PI数据。

## 1. 为什么组合？

CytoTRACE2预测分化潜能，scTour给动态相对排序；把两个不同概念并列，有助于研究潜能预测是否沿状态路径系统变化。

## 2. 比单方法多解决什么？

区分模型的“相对早晚”与“预测潜能”，发现两者相容或脱钩的状态。FitDevo保留为后续独立补充，本次不额外安装。

## 3. 需要什么输入？

按各官方要求准备表达尺度、物种/基因ID、模型覆盖；冻结共同细胞、谱系、供者、测序深度/检测基因数/细胞周期。CytoTRACE2的未log输入不能先被通用管线统一log化；许可及模型资源先查。

## 4. 按照什么顺序运行？

先验证两个单方法；对照原始分数/类别/时间定义，独立核查方向，再按同细胞匹配，最后按谱系与供者分层检查潜能—time关系和技术混杂。不得用潜能先定根再拿同潜能证明该根正确。

## 5. 哪些量可以比较？

可比较谱系内秩趋势和类别组成；不能令1−scTour time等于潜能，不能平均标准化分数为“综合干性”，也不能把Palantir分化熵混进同一尺度。

## 6. 怎样判断一致？

先核查高分含义，绘制分层散点、深度/检测基因关系和供者分布，报告相关方向及不确定性。相反相关是否合理取决于已核实的time方向，不能自动反转来凑一致。

## 7. 冲突怎样解释？

检查训练域、基因覆盖、应激/炎症导致的复杂度变化和测序深度。STOP于物种/覆盖不合格或技术因素主导；PIVOT为覆盖/混杂审计及标志物描述，不命名去分化。

## 8. 最终论文图件与边界

预测分数/类别和时间并列、潜能—时间散点、供者分层与混杂诊断、覆盖表。可提出候选状态的潜能假说，需克隆、分化或功能实验，不把炎症高分当实测干性。
