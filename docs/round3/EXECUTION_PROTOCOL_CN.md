# 第三轮实际执行范围与官方教程差异

本项目复现官方小例的输入、方法与主要分析步骤，所有结果均由本机计算；并不声称跨软件版本逐数值或逐像素复制旧教程。官方来源与固定版本见[SOURCES](SOURCES.json)，当前环境见[包清单](../../environments/round3/installed_packages.csv)。

- tradeSeq沿用包内countMatrix、crv、celltype、6个结点和seed=7。官方旧Rmd设置RNGversion("3.5.0")；本轮保留R 4.6默认Mersenne-Twister / Inversion / Rejection，未切回旧采样器。因此随机谱系分配不保证与旧教程一致。240个基因不是全基因组，未执行evaluateK；额外eigen求逆只作敏感性分析，默认NA保留。
- Monocle3采用官方仓库内worm_embryo小例，而非下载整个大型教程数据。按官方流程独立降维、对齐、学习主图、选择根和检验动态基因；M06限定同一分区内的局部路径，不拼接断开的分区。
- 组合另用同一官方小例中650个细胞；三个方法共享细胞ID与原始计数来源，各自按算法要求处理。没有拼接Paul15和线虫数据。主要对齐流程与事后不对齐敏感性分别保存；AWA终点FAIL不能用更高敏感性相关替代。
- GO为有明确检验背景的生物过程过度富集分析，不是带方向GSEA。GAF与OBO发布日期不同，归属及衍生处理见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

三模块经交付入口在新R会话串行重跑，47张数值TSV校验一致。三种图格式均检查可读取和渲染，但PDF设备时间元数据等可能随导出变化；不要求所有图文件跨运行逐字节一致。详见[图件检查](ARTIFACT_QA.json)和[最终入口日志](FINAL_USER_ENTRIES.log)。

模型执行成功与科学结论分别验收；未运行真实PI。已安装环境通过加载和运行，未在第二套全空包库验证完整安装，也未验证BPCells磁盘对象迁移。官方弃用提示与安装失败日志保留，运行时不随交付包分发。
