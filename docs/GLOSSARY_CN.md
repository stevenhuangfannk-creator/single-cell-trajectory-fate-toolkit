# 常用术语：中文、英文与解释边界

| 中文 | 英文或缩写 | 含义与不能混淆的量 |
|---|---|---|
| 轨迹/谱系 | trajectory / lineage | 模型中的状态路径，不等于实测祖先后代 |
| 拟时序 | pseudotime | 条件于模型与方向的相对排序，不是实验时间 |
| 主成分分析 | PCA | 线性低维表达空间；维数需核查 |
| 统一流形近似与投影 | UMAP | 常用二维展示；距离与图上分叉不自动代表生物过程 |
| 扩散拟时序 | DPT | 基于扩散结构的相对距离/排序，需起点 |
| 最小生成树 | MST | 用边连接节点的树形骨架，不是速度或概率 |
| 主曲线 | principal curve | 穿过数据分布的平滑曲线 |
| 曲线归属权重 | curve assignment weight | 对谱系曲线的归属/贡献，默认可共享，不要求跨谱系行和1 |
| 命运概率 | fate probability | 给定转移模型和终末定义的预测，不是实测转化频率 |
| 分化潜能 | potency | 模型预测的分化能力相关量，不能直接当实测干性 |
| 干性 | stemness | 与自我更新等功能有关的概念，需要相应实验验证 |
| RNA速度 | RNA velocity | 剪接动力学推断的短时表达方向，不是细胞空间迁移 |
| 已剪接/未剪接 | spliced / unspliced，S/U | 真实分子计数层，不能从普通表达编造 |
| 潜在时间 | latent time | 动力学模型推断的时间，不等于实验采样时间 |
| 原始计数 | raw counts | 原始分子/reads计数尺度；字段名raw不能替代来源追溯 |
| 唯一分子标识符 | UMI | 识别分子重复的标签，UMI计数与普通reads计数不同 |
| 高斯混合模型 | GMM | 用多个高斯分布描述群结构，本次140点例不重新聚类 |
| 负二项广义加性模型 | NB-GAM | 以平滑函数描述计数随拟时序变化，需模型诊断 |
| 归一化偏移项 | offset | 计数模型中校正测量规模等因素的项，非任意减去常数 |
| 错误发现率 | FDR | 一组检验的多重校正概念，不是每个发现的因果概率 |
| 基因集富集分析 | GSEA | 对指定基因排序考察功能集分布，背景与方向须明确 |
| 基因集变异分析 | GSVA | 表达层面的基因集评分，与GSEA检验量不同 |
| 标准化富集分数 | NES | GSEA输出之一，不与任意通路分数直接相加 |
| 最优传输 | OT | 在成本、边际和增长等假设下估计质量匹配 |
| 耦合 | coupling | 源与目标之间质量分配，未必是行和1的转移矩阵 |
| 转移核 | kernel | 根据方向/邻域等构造转移倾向；来源必须明确 |
| 宏状态/终末状态 | macrostate / terminal state | 图模型的聚合状态/终末定义，不自动等于细胞类型或不可逆命运 |
| 熵 | entropy | 当前概率分布的不确定性，不是不同模型共用的“干性”单位 |
| 桑基图 | Sankey | 用宽度表示汇总流量，宽度不等于逐个细胞的实测路线 |
| 停止/转向条件 | STOP / PIVOT | 科研工作流的决策规则，不是算法输出 |

方法名、包名、API函数和对象字段保留英文以便检索；实际教程在首次讨论科学量时给出中文解释。含义不同的同名量不因标准化就可平均。PI专题中的ECM为细胞外基质，Integrin为整合素，FAK为黏着斑激酶，YAP/TAZ为机械转导相关转录共调控因子。
