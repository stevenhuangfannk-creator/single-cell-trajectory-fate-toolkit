# 第三轮：State 1/6/7 动态基因与功能程序研究设计

**DESIGN_ONLY：本轮未读取、运行或上传真实PI数据。** State 1、6、7是既有注释标签，不携带先后顺序；1→6→7只是待证伪假设。不得把本仓库的线虫/小鼠示范结果转述为PI纤维母细胞的研究发现。

## 科学问题与可区分假设

1. 三个状态是否有连续表达结构，还是三个离散群/不同供者构成的混合？用Slingshot与Monocle3独立估计并检查局部覆盖、分区与根方向，不能通过手动连线获得连续性。
2. ECM（细胞外基质）合成、降解和重塑是否同向、错峰或分支特异？用tradeSeq拟合基因，再在明确背景下研究预登记程序；总ECM评分不能替代三个过程的分别分析。
3. Integrin–FAK–YAP/TAZ机械转导相关转录程序是否与ECM程序共同变化？相关性只产生候选关系；FAK磷酸化、YAP/TAZ核定位和基质硬度须另测。
4. PI/Healthy差异是状态构成改变、进程位置改变，还是相同位置的表达改变？三者须分别建模，不可从混合细胞的伪时间差异直接推疾病重编程。
5. 炎症/修复程序与内皮微环境是否存在可检验衔接？先建立稳定的纤维母细胞状态模型，再对独立表达及空间/实验信息评估配体–受体候选；本模块不推断细胞间因果信号。

## 输入与样本单位

需要原始RNA计数、基因稳定ID/符号映射、每个细胞的供者、PI/Healthy、样本批次、组织位置、状态注释、质量控制指标、细胞周期和双细胞标记。需要一个供者×状态×条件覆盖表，明确稀缺组合。临床分组若完全与批次混杂，统计模型无法凭计算分离疾病与技术因素。

AnnData导出时核实counts层并转置；Seurat从RNA assay的counts层取数。整合表达只用于某些低维可视化，不能替代NB-GAM的原始计数。供者才是疾病比较的生物重复单位；细胞数量多不能补偿供者不足。

## 预先登记的表达程序

| 程序 | 候选转录指标（仅供审查，需依物种/版本确认） | 必须区分的限制 |
|---|---|---|
| ECM合成 | COL1A1、COL1A2、COL3A1、FN1 | 胶原mRNA不等于已沉积胶原量 |
| ECM降解/平衡 | MMP家族、TIMP1/2 | 蛋白酶mRNA不等于酶活，MMP/TIMP需联合解释 |
| ECM重塑/交联 | LOX、LOXL、POSTN等 | 交联和机械硬度需独立测量 |
| 机械转导 | ITGA/ITGB、PTK2、CCN1/CCN2、ANKRD1 | YAP1/WWTR1表达不等于YAP/TAZ活性或核定位 |
| 炎症 | 经审查的NF-κB、干扰素、趋化因子集合 | 炎症高不等于病理驱动，也可能是旁分泌响应 |
| 修复 | 物种和组织匹配的修复/创伤反应集合 | 修复与纤维化可能重叠，不能以单个基因命名终末命运 |

基因集来源、版本、下载日期、物种映射、集合大小、重叠基因及缺失率均需登记。同一胶原基因出现在多个集合中不构成多个独立证据。不得临时挑选最符合故事的基因集。

## 串行分析顺序

00统一配置、锁定细胞与计数；01检查供者/状态覆盖并做质量审查；02分别建立Slingshot与Monocle3轨迹，记录降维、聚类/分区、候选根及无法到达的细胞；03按共同细胞、匹配根和候选终点逐谱系比较；04使用tradeSeq在可信谱系上拟合计数与供者/条件设计；05按预登记对比构建动态基因列表和可解释功能排序；06仅从保存结果绘图，最后形成局限报告。

拟合供者固定效应或条件协变量并不会自动解决所有重复结构，也不等于一个已验证的供者随机效应模型。疾病关联应设计供者层面汇总或合适的重复模型，进行留一供者、供者内重采样与条件分层敏感性分析。供者数不足时以描述和效应估计为主，不把细胞级p值推广为人群结论。

## 动态检验和功能分析的适当对应

associationTest用于先找动态形状，不提供唯一方向。startVsEndTest回答特定路径早晚是否不同；patternTest比较路径整体模式；diffEndTest比较计算终点；earlyDETest只用于预先定义的结点区间。不同路径相对时间0.5不保证阶段一致，须结合注释/实验时间匹配。

ORA（过度富集分析）的背景必须是通过质量过滤、实际被模型检验且能映射到注释的基因，不能用“全人类基因”替代本实验背景。全基因组GSEA（基因集富集分析）需要不按显著性预筛选的可解释有方向排序；多自由度Wald统计不能任意添加符号。可对明确谱系的早晚对比构建签名，并同时报告表达效应、覆盖与FDR。通路富集支持转录程序关联，不能单凭它称通路被生化激活。

## STOP / PIVOT 条件

- **STOP**：ID不一致、计数来源不明、组别与批次完全混杂、关键状态仅由单个供者支撑、根在不同分析中没有依据、分区无法连接、两算法的候选终点不能可靠匹配。此时不合成全局拟时序、不解释疾病状态转换。
- **PIVOT**：若状态连续性不稳，转做状态间供者层面差异与程序构成；若只有局部路径可匹配，只研究局部路径；若注释映射率低，先修复ID，不继续富集；若分支覆盖不足，不做早期分支DE。
- **实验衔接**：ECM沉积/酶活、基质硬度、FAK磷酸化、YAP/TAZ定位、扰动和时间序列可检验候选机制；内皮互作需在供者/组织位置匹配后独立评估。
