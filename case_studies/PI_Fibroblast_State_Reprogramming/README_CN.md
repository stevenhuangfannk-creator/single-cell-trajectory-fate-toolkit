# PI Fibroblast State Reprogramming：教学性分析设计

**状态：DESIGN_ONLY；真实PI数据未读取、未分析。** 本页的图件与状态变化都是预设问题，不是已得结果。“Reprogramming”是研究假说用语。



本专题路径：`case_studies/PI_Fibroblast_State_Reprogramming/`。仅制定方案，不读取或运行真实 PI 数据。题目中的“重编程”是待研究问题，不是结论；State 1/6/7 不预设起点、终点或顺序。

输入清单：经确认的成纤维细胞对象、原始计数、固定注释和坐标、供者/样本/PI或Healthy/批次、质量控制记录、物种/基因版本；如存在则另登记真实采样时间与真实剪接层。临床分组不能充当实验时间，同一供者的多个细胞不是多个独立生物重复。

| 问题 | 教学分析与预期图 | 可解释结论与外部验证 |
|---|---|---|
| State 1/6/7 是否连续 | 先检查谱系纯度、供者覆盖、群间邻域和密度；A模块分别拟合，固定坐标并列；画断连细胞与排序分歧 | 支持“表达状态连续性/分支的模型证据”；需根依据、纵向或谱系证据才能谈转化方向 |
| ECM 合成、降解、重塑是否分离 | ECM 为细胞外基质；预登记独立基因集，检查表达覆盖；B模块画胶原/基质、蛋白酶与抑制因子等趋势、热图、程序对比 | 转录程序变化；不能仅凭 mRNA 推断胶原沉积、降解通量或净纤维化；需蛋白、组织和功能实验 |
| Integrin–FAK–YAP/TAZ | Integrin为整合素，FAK为黏着斑激酶，YAP/TAZ为机械转导相关转录共调控因子；分别看受体、下游靶程序及技术混杂 | 表达程序与机械转导假说相容；PTK2/YAP1/WWTR1转录量不等于磷酸化/核定位，需蛋白定位、力学或干预 |
| 炎症与修复状态 | 使用预定义炎症/修复程序，按供者展示；轨迹内比较与疾病分组比较分开 | 描述关联与异质性；供者级差异需适当重复设计，不能用逐细胞显著性宣称临床机制 |
| 预测潜能与候选终末 | C模块评估基因覆盖和读深混杂；D模块检验不同起点/终末定义；画分数、概率、终末组成和敏感性 | 产生候选状态与实验优先级；不证明去分化、多能性或不可逆终末 |
| 内皮微环境衔接 | 后续保存样本/供者一致的细胞类型、配体受体表达、空间/分泌证据；先画候选关系，不自动扩展方法依赖 | 配体受体共表达是互作假说；需空间邻近、蛋白/分泌、阻断或共培养验证 |

预登记展示 COL1A1/COL1A2 等 ECM 候选或 CTGF/CCN2、CYR61/CCN1 等靶程序时，先核对物种、同义名、测序覆盖与文献依据，不能把示例基因表当普适且已验证的通路评分标准。

STOP 条件：谱系混入、ID/尺度不明、批次与疾病完全混杂、候选状态仅由单供者支持、根或方向无依据、断连无法解释、计数/剪接层缺失、模型不收敛、资源超预算。阈值应在查看结果前按真实设计登记，不为通过结果事后调阈值。

PIVOT 条件与动作：无方向依据就转为无方向状态结构和表达程序描述；轨迹不稳就报告拓扑分歧及参数/供者敏感性；潜能受深度解释就报告混杂而不命名去分化；无剪接层不运行 E；无真实时间不运行 F。临床重复不足时保留探索性图，不声称供者级推断。方法冲突是结果，应解释而非删细胞凑一致。
